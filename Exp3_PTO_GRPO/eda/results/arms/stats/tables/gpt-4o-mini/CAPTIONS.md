- **friedman_omnibus** — Friedman repeated-measures omnibus across iterations per arm x rubric (chi2, p, Kendall's W), all four arms; grader = gpt-4o-mini (primary oracle = the training reward). Unit = persona (persona_id x iteration pivot, base included; n_personas = complete rows). No sign convention (an omnibus). GRPO_LA5 was trained to iteration 5 (the other arms to 10), so its final/last rows are iteration 5 and its trajectory statistics span 6 iterations. Thin arms dropped.
- **main_results** — FINAL and BEST iteration vs base per arm x metric (column `target`), all four arms; grader = gpt-4o-mini (primary oracle = the training reward). persona-paired (persona_id, N=96 shared personas; never file_index): delta = target - base (+ => trained model higher; MICI is lower-better so + is worse there), paired Cohen's dz + label, Wilcoxon p (Holm across rubrics within arm x target), bootstrap 95% CI (BOOT_SEED), trajectory Spearman rho / OLS slope. BEST = the arm's peak iteration on its own training oracle (best_per_experiment). GRPO_LA5 was trained to iteration 5 (the other arms to 10), so its final/last rows are iteration 5 and its trajectory statistics span 6 iterations. Thin arms (<3 scored iters) dropped.
- **rubric_pca_pc1** — Variance explained by PC1 of the standardized rubric scores per arm (canonical 10-metric factor space, pooled over every conversation x iteration of the arm), all four arms; grader = gpt-4o-mini (primary oracle = the training reward). A dominant PC1 => the rubrics ~ one latent factor, so 'every metric up' is weak evidence of multi-skill gain. Unit = conversation; no pairing, no sign. GRPO_LA5 was trained to iteration 5 (the other arms to 10), so its final/last rows are iteration 5 and its trajectory statistics span 6 iterations.
- **slope_by_arm** — Per-iteration OLS slope + Spearman rho per arm x metric (climb rate; peak_iter vs final_iter flags a post-peak regression), all four arms; grader = gpt-4o-mini (primary oracle = the training reward). Pooled persona x iteration rows (unit = conversation), so NO p is reported -- descriptive; the repeated-measures omnibus is friedman_omnibus. + slope => the metric climbs with iteration (MICI is lower-better, so + is worse there). GRPO_LA5 was trained to iteration 5 (the other arms to 10), so its final/last rows are iteration 5 and its trajectory statistics span 6 iterations. Thin arms dropped.
- **vs_base_paired** — Each arm x iteration vs its OWN base on Q1+Q2 -- one merged table (column `arm`), all four arms; grader = gpt-4o-mini (primary oracle = the training reward). persona-paired (persona_id, N=96 shared personas; never file_index): mean_delta = iteration - base (+ => later policy higher), Wilcoxon p, dz, Holm p (across iterations WITHIN each arm), bootstrap 95% CI (BOOT_SEED). GRPO_LA5 was trained to iteration 5 (the other arms to 10), so its final/last rows are iteration 5 and its trajectory statistics span 6 iterations.
